## The entry

> That cul-de-sac has a lovely view of the wedding you are now late for. The map's fault, obviously.

(98 characters, one line, in the GPS's own smug, defensive voice.)

## How it works

`main.py` (Python 3 standard library only) writes the entry to `/output/entry.txt`, validates it against the competition gate (1–200 UTF-8 characters, a single line, not blank), and reads it back byte-exact before exiting.

Run it:

```sh
python3 main.py
```
